## ✨ Возможности

- **Кастомный HUD** — здоровье, броня, голод, деньги, оружие и количество патронов.
- **Табло захвата** — отображение счёта атаки и защиты, названий сторон и времени захвата.
> ⚠️ **Важно:** Табло захвата пока находится на стадии тестирования. Из-за недостаточного количества проверок его отображение и работа могут быть некорректными. Возможны ошибки в отображении счёта, таймера и других элементов. Если обнаружите проблемы, сообщите о них.
- **Настройка интерфейсов** — возможность самостоятельно задавать правила скрытия и отображения HUD.
- **Быстрая перезагрузка** — применение изменений без перезапуска игры.

## 📥 Установка

1. Откройте раздел [Releases](../../releases).
2. Скачайте актуальную версию `RadmirHud.asi`.
3. Закройте игру.
4. Откройте папку RADMIR CRMP, где находится `gta_sa.exe`.
5. Скопируйте `RadmirHud.asi` в эту папку.
6. Добавьте рядом файл `RadmirHud.json`. (необязательно)
7. Запустите игру.

**Важно:** для работы плагина необходим установленный ASI-загрузчик.

## ⚙️ Настройка HUD

Файл `RadmirHud.json` находится рядом с `RadmirHud.asi`.

Пример конфигурации:

```json
{
    "hide-interfaces": [],
    "show-interfaces": ["CarsShop"]
}
```

**Параметры:**

- `hide-interfaces` — интерфейсы, при открытии которых HUD дополнительно скрывается.
- `show-interfaces` — интерфейсы, при которых HUD принудительно остаётся видимым.

Изменения применяются по нажатию `F10` или при следующем запуске игры.

### Автоматическое скрытие HUD

Начиная с версии **v1.0.9**, HUD автоматически скрывается при открытии полноэкранных игровых меню:

- Настройки игры.
- `/mn`.
- Игровая карта.
- `MainMenu`.
- `PauseMenu`.
- `FastMap`.
- Другие интерфейсы, для которых игра запрашивает скрытие HUD.

После закрытия меню HUD автоматически возвращается.

Частичные окна, например `/car`, не скрывают HUD.

## 🛠️ Для разработчиков

### Технологии

- C++17 — ASI-плагин.
- React — интерфейс HUD.
- TypeScript — логика и обработка игровых данных.
- Vite — сборка JavaScript-бандла.

### Структура проекта

| Папка / файл | Назначение |
|---|---|
| `src/` | Исходный код HUD |
| `src/radmirBridge.ts` | Связь с игровыми интерфейсами |
| `dist/` | Собранный JS-бандл |
| `asi_plugin/` | Исходники ASI-плагина |
| `asi_plugin/src/dllmain.cpp` | Внедрение HUD в игру |
| `scripts/` | Вспомогательные скрипты |
| `package.json` | Зависимости и команды сборки |

### Сборка проекта

Необходимые инструменты:
- Node.js и npm.
- Visual Studio C++ Build Tools с поддержкой x86 или llvm-mingw i686.

Команды сборки:

```bash
npm ci
npm run build:inject
cmd /c asi_plugin\build-asi.bat
```

Готовый `RadmirHud.asi` появится в папке `asi_plugin`.

## 🔧 Совместимость

Плагин поддерживает совместную работу с:

- `aTools-R-RP`
- `loader-js`
- `scripts/_otools.js`

Механизм взаимодействия с игровыми функциями защищён от рекурсивных вызовов сторонних обёрток.

## ℹ️ Дополнительная информация

- Плагин не отправляет сетевые запросы.
- Исходные файлы игры `uiresources` и `manifest.json` не изменяются.
- Штатный HUD скрывается только после успешной отрисовки кастомного интерфейса.
- Если кастомный HUD не запускается, штатный интерфейс сохраняется.
- Для диагностики работы создаётся файл `RadmirHud.log`.
